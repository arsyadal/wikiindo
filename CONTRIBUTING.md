# Berkontribusi

WikiIndo menyusun informasi pemerintahan publik dengan rujukan yang dapat diperiksa. Silakan gunakan [form isu](https://github.com/arsyadal/wikiindo/issues/new/choose) untuk kritik atau saran, koreksi data beserta sumber dan tanggalnya, atau laporan bug dengan langkah reproduksi. Isu bersifat publik; jangan kirim kata sandi, rahasia, nomor identitas, alamat atau kontak pribadi, maupun informasi nonpublik.

Untuk menambah atau memperbaiki catatan pejabat, instansi, atau LHKPN, ikuti [panduan penulisan data](content/README.md). Panduan itu menjelaskan struktur berkas Markdown, hubungan slug, sumber, dan periode. Jangan menambahkan catatan yang tidak didukung sumber.

Untuk perubahan kode atau dokumentasi, ajukan pull request dengan ringkasan perubahan dan pemeriksaan yang relevan. Template pull request meminta verifikasi sumber untuk perubahan data, pemeriksaan kode, serta konfirmasi bahwa perubahan tidak memuat informasi sensitif.
