# WikiIndo

> **Buat Indonesia Lebih Transparan** — Basis data terbuka dan platform informasi kabinet serta lembaga pemerintahan Republik Indonesia.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Runtime & Package Manager:** [Bun](https://bun.sh/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Validation & Parsing:** Zod, gray-matter, React Markdown

## Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your machine.

### Installation

```bash
bun install
```

### Running Development Server

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Typecheck & Tests

```bash
bun run typecheck
bun test
```

### Production Build

```bash
bun run build
bun run start
```
