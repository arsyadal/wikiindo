# Pelaporan kerentanan keamanan

Jangan laporkan kerentanan melalui isu, pull request, diskusi, atau kanal publik lain. Informasi kerentanan dapat membahayakan pengguna jika dipublikasikan sebelum ditangani.

Saluran pelaporan privat untuk repositori ini belum dapat diverifikasi. Pemilik repositori perlu mengaktifkan GitHub Private Vulnerability Reporting terlebih dahulu. Setelah fitur itu aktif, gunakan **Security → Advisories → Report a vulnerability** di [halaman Security repositori](https://github.com/arsyadal/wikiindo/security). GitHub akan menampilkan formulir privat hanya jika pelaporan privat tersedia bagi repositori ini.

Sampai saluran privat itu tersedia dan terkonfirmasi, jangan kirim rincian kerentanan melalui kanal publik. Kebijakan ini tidak menjanjikan kerahasiaan atas laporan yang dikirim lewat kanal publik.
